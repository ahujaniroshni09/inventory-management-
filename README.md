# Inventory Management System

## Project Description

The Inventory Management System is a Python-based project used to manage products, employees, sales, and inventory reports.

## Main Features

1. User Login
2. Add Product
3. View Products
4. Sell Product
5. Add Employee
6. View Employees
7. Inventory Report

## Technologies Used

- Python
- SQLite
- VS Code

## Project Modules

- database.py - Database management
- auth.py - Login and authentication
- inventory.py - Product management
- billing.py - Sales management
- employee.py - Employee management
- reports.py - Inventory reports
- main.py - Main program

## Testing

The project includes a testing file named `test_inventory.py` to test product addition.

## How to Run

Open the project in VS Code and run `main.py`.
