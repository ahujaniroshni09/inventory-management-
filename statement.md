# Project Statement

## Project Title

Inventory Management System

## Problem Statement

Managing products manually can make it difficult to keep track of
product details, stock quantity, sales, and employees.

This project provides a simple computer-based system to manage
inventory information in an organized way.

## Objectives

- To add and manage product information.
- To view available products.
- To manage product sales.
- To manage employee information.
- To generate inventory reports.
- To store product information using a database.

## Functional Requirements

1. User authentication
2. Product management
3. Sales management
4. Employee management
5. Inventory reporting

## Non-Functional Requirements

1. Usability
2. Reliability
3. Error handling
4. Maintainability

## Technologies Used

- Python
- SQLite
- VS Code

## Conclusion

The Inventory Management System provides a simple and organized
way to manage products, employees, sales, and inventory information.
